# What is LLMs?

An LLM is a type of artificial intelligence that can read, understand, and generate human-like text.

Think of it as a super-smart text robot that learned how language works by reading a LOT of text from books, websites, articleås, and more.

* An LLM is a program (not a computer itself) that has been trained on huge amounts of text. It learns patterns in how we use language, how words appear together, grammar, tone, and meaning, so it can understand or generate text that sounds natural.
* LLM is a type of AI program that can do particular tasks (recognize or generate text)
* LLM uses a type of machine learning named deep learning to understand how characters, words, and sentences work together. These models don’t just memorize; they learn patterns about how words are used in different contexts.
  * These deep learning models essentially can train themselves to be more better
* LLMs are based on a special type of deep learning model called a Transformer. This model is very good at understanding context: it looks at all the words in a sentence (not just left-to-right) to figure out meaning.
* LLMs are trained on huge sets of data&#x20;
* LLMs are also fine-tuned or prompt-tuned to do a particular task

## What are LLMs used for?

LLMs are mostly used in **Generative AI,** meaning they can **create text** when you give them a prompt (instruction or question).

You type something, and the model **generates a reply** that sounds natural, like a human.
