# AI Engineer Requirements

#### Phase 1: The Foundation (Week 1)

Goal: Master the coding and math basics required to build AI systems.

* Python for Engineering:
* OOP: Learn Classes, Inheritance, and clean code structure
* Async/Await: Learn asynchronous Python
* FastAPI:
* Build a simple API that accepts text and returns a response.
* Math Refresh:
* Review Matrix Multiplication (the engine of Neural Networks) and Vectors.

#### Phase 2: LLMs & RAG (Week 2)

Goal: Learn the core text technologies mentioned (LLMs + RAG).

* The Transformer:
* Understand the "Attention Mechanism" (how models understand context).
* Learn the difference between Encoders (BERT) and Decoders (GPT).
* RAG Pipeline:
* Embeddings: Learn how to turn text into numbers (vectors).
* Vector Storage: Learn to use PostgreSQL with pgvector
* Retrieval: Build a script that retrieves relevant text chunks based on a user question.

#### Phase 3: Fine-Tuning & RLHF (Week 3)

Goal: Move from "using" models to "training" them

* Fine-Tuning:
* Learn PEFT (Parameter-Efficient Fine-Tuning).
* Focus specifically on LoRA and QLoRA (techniques to train huge models on smaller hardware).
* Reinforcement Learning (RLHF):
* Understand the loop: Pre-training -> Supervised Fine-Tuning -> RLHF
* Study DPO (Direct Preference Optimization), a popular and simpler alternative to PPO for aligning models.

#### Phase 4: Multimodal AI (Week 4)

Goal: Handle Audio and Vision, not just text.

* Vision (VLM):
* Study CLIP (connecting images to text) and LLaVA (talking to images).
* Audio (STT & TTS):
* STT: Implement OpenAI Whisper locally to transcribe audio.
* TTS: Experiment with Coqui TTS or VITS to generate speech.

#### Phase 5: Production Engineering (Week 5)

Goal: Build the infrastructure to run these models in the real world.

* Databases:
* MongoDB: Learn to store unstructured data (like chat logs and model metadata).
* PostgreSQL: Design schemas for user data and structured records.
* Deployment:
* Docker: Containerize your FastAPI application.
* GPU Cloud: Learn how to deploy your container on a GPU cloud (like RunPod or AWS) rather than just running it on your laptop.

#### Phase 6: Capstone Project (Week 6)

Goal: Build a portfolio piece that combines everything.

* The Project: Build a "Multimodal RAG Assistant."
* User uploads a PDF and an Image.
* VLM analyzes the image.
* RAG searches the PDF.
* LLM combines both insights into an answer.
* TTS reads the answer out loud.
* FastAPI serves it all.
